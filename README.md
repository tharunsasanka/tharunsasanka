## `> whoami`

I am a **BSc (Hons) Computer Security undergraduate** at **NSBM Green University**, studying in partnership with the **University of Plymouth**.

My main interests sit at the intersection of **cybersecurity, digital forensics, incident response and software engineering**. I enjoy turning security concepts into practical tools and building applications with security considered from the ground up.

## `> featured_projects`

### `01` AI-Powered DFIR Investigation Assistant

A cybersecurity investigation platform designed around **digital forensics and incident response workflows**.

**Capabilities**

`Log Analysis` · `Timeline Reconstruction` · `Suspicious Activity Detection` · `MITRE ATT&CK Mapping` · `Evidence Management` · `AI-Assisted Reporting` · `Threat Intelligence` · `Chain of Custody`

**Stack**

`React` `TypeScript` `Tailwind CSS` `FastAPI` `PostgreSQL` `Docker`

---

### `02` CyberPortfolio

A modern cybersecurity-focused portfolio platform combining a public developer profile with a secure management layer.

**Features**

`Projects` · `Certificates` · `Skills` · `Cyber Labs` · `Contact Inbox` · `AI Assistant` · `Certificate Verification`

**Stack**

`React` `TypeScript` `Tailwind CSS` `MongoDB`

---

### `03` Healthcare Cryptography System

A secure healthcare application exploring practical security controls for sensitive data and authenticated application workflows.

**Security Areas**

`JWT Authentication` · `Role-Based Access Control` · `Medical Record Protection` · `AES Encryption` · `Security Analysis`

---

### `04` IoT Flood Warning System

An ESP32-based environmental monitoring system designed to detect changing flood-risk conditions and provide automated alerts.

**Components**

`ESP32` · `Water Level Sensor` · `Rain Sensor` · `Soil Moisture Sensor` · `Weather Data` · `Cloud Alerts`
