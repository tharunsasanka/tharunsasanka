## `> featured_projects`

### AI-Powered DFIR Investigation Assistant

A digital-forensics platform designed to assist investigators with:

- Automated forensic timeline generation
- Suspicious activity detection
- MITRE ATT&CK mapping
- Evidence and chain-of-custody management
- AI-generated investigation summaries
- Security findings and reporting
- Threat intelligence enrichment

**Stack:** React, TypeScript, FastAPI, PostgreSQL, Docker and AI integration

---

### CyberPortfolio

An animated cybersecurity portfolio with:

- Hidden administrator portal
- Project and certificate management
- Skills and cyber-lab management
- Contact inbox
- Command palette and dynamic animations
- Full-stack CRUD functionality

**Stack:** React, TypeScript, Node.js, Express and MongoDB

---

### Healthcare Cryptography System

A healthcare application designed to demonstrate secure management of sensitive medical information.

- Role-based access control
- JWT authentication
- Medical record management
- AES encryption and decryption
- Encryption mode comparison
- Security and performance analysis

**Stack:** Python, Flask, JavaScript and SQLite

---

### IoT Flood Warning System

An ESP32-based early-warning solution using environmental sensors and cloud monitoring.

- Water-level monitoring
- Rain and soil-moisture detection
- Temperature and humidity monitoring
- Firebase integration
- Alerts and voice notifications

**Stack:** ESP32, Firebase, IoT sensors and embedded programming
